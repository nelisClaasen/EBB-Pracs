\section{Discussion}

For the most part, the general shape of the plots matched that of the simulations, with the largest exceptions being state one for the disturbance rejection PID and state one for reference tracking PID.

It is evident for state one for the disturbance rejection PID that the system was not cooled down to room temperature before the controlling commenced. For state one for the reference tracking PID, various results were found, which are believed to be due to the already weak disturbance rejection (due to the controller being tuned for reference tracking) causing a significant effect due to external disturbances.
