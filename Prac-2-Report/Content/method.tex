\section{Design and Simulation}
\subsection{PD Controller}
The parameters found using Matlab's \texttt{pidtune} function were: $K_p = 4.58$, $K_i = 0.0$, and $K_d = 0.0$.
The controller was then simulated using the Simulink model below.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{Images/PID_ref_track_model.pdf}
    \caption{Simulink Model used for PD Controller}
    \label{fig:PD_simulink_model}
\end{figure}

The resulting model was then used to find the following step response parameters using Matlab's \texttt{stepinfo} function.

\begin{tblr}{colspec={X|XX}, row{even} = {bg = gray!20}}
    Step Response Parameter & Closed Loop & Open Loop \\
    \hline
    Overshoot ($\%$) & $8.8047\times 10^{-5}$ & $0.0$ \\
    Rise Time ($\mathrm{s}$) & $77.3698$ & $251.4783$\\
    Peak Time ($\mathrm{s}$) & $119.1159$ & $1500$\\
    Settling Time ($\mathrm{s}$) & $97.0706$ & $446.5085$\\
\end{tblr}

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{../Matlab_Code/PD_and_PID_reference_tracking/PD_open_vs_closed.pdf}
    \caption{Closed Loop vs Open Loop response of PD Controller}
\end{figure}

\subsection{PID - Reference Tracking Controller}
The parameters found using Matlab's \texttt{pidtune} function were: $K_p = 0.112$, $K_i = 0.000935$, and $K_d = 0.0$.

The following step response parameters where then found using the model:

    Peak Time ($\mathrm{s}$) & $432.7289$ & $1500$\\
    Settling Time ($\mathrm{s}$) & $220.6166$ & $446.5085$\\
\end{tblr}
