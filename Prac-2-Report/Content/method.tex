\section{Design and Simulation}
\label{sec:design}

The previous First Order Plus Dead Time (FOPDT) models made using Matlab's \texttt{tfest} function were used to construct the simulation models used in this practical.

\begin{equation}
    G_{11} = \frac{0.1175}{s + 0.007592}\label{eq:G11}
\end{equation}

\begin{equation}
    G_{12} = \frac{0.05949}{s + 0.0060685}\label{eq:G12}
\end{equation}

Matlab's \texttt{compare} function was then used to confirm $G_{11}$'s accuracy. It was found to be $\approx94\%$ accurate.

\subsection{P Controller}

The Proportional (P) controller was designed using MATLAB's \texttt{pidtune} function applied to the transfer function $G_{11}$ identified in Practical 1.
The resulting controller has the form $C(s) = K_p$, where the proportional gain was tuned to achieve a phase margin of \SI{60}{\degree}.
The P controller produces a fast initial response but introduces a steady-state error because, without an integral term, the controller output falls to zero as the error approaches zero.

\begin{lstlisting}[style=Matlab-editor, caption={P Controller Design (MATLAB)}]
[C1_p, info] = pidtune(G11, 'P');
\end{lstlisting}

The controller was then simulated using the Simulink model shown in \cref{fig:p_simulink_nodist,fig:p_simulink_dist}.

\subsection{PI Controller}

The Proportional-Integral (PI) controller was designed by adding an integral term to eliminate the steady-state error observed in the P controller.
The controller has the form $C(s) = K_p + \frac{K_i}{s}$, which ensures that the integral term accumulates the error over time and drives the steady-state error to zero.
The trade-off is a slower response and increased overshoot compared to the P controller.
The same Simulink models shown in \cref{fig:p_simulink_nodist,fig:p_simulink_dist} were used, with the PI gains loaded into the PID Controller block.

\begin{lstlisting}[style=Matlab-editor, caption={PI Controller Design (MATLAB)}]
[C1_pi, info] = pidtune(G11, 'PI');
\end{lstlisting}

The tuned gains and step-response metrics for the closed-loop system are summarised in \cref{tab:pi_gains,tab:pi_metrics}.
